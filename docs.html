Introduction

Welcome to the official Affer documentation. Our templates are designed to be easy to customize, high-performance, and SEO-optimized out of the box.

Quick Start

Ensure you have Node.js installed if you are using the Next.js or React versions of our templates.

Installation

After purchasing a template, unzip the package and navigate to the project folder:

cd project-name
npm install
npm run dev

Theme Configuration

You can customize the global colors and fonts in the style.css file or tailwind.config.js depending on the template.

:root {
  --primary: #5B21B6;
  --accent: #EC4899;
}
